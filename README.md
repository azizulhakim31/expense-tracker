# Expense Tracker

A simple personal expense tracker built with HTML, CSS, and JavaScript.

## Features
- Add income and expense transactions
- Track balance, income, and expenses in real time
- Search transactions by name
- Delete individual transactions
- Persist data in browser localStorage

## Project Structure
- `index.html` – app structure
- `style.css` – styling and responsive layout
- `script.js` – app logic and localStorage handling

## Run locally
Open `index.html` in your browser to use the app.

## Notes
This app stores transaction data in the browser, so your entries remain saved after refresh on the same browser/device."
